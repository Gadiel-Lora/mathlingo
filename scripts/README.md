# Scripts

Operational scripts are grouped by purpose:

- `db/`: database setup and migrations.
- `seed/`: initial academic data and exercise seeds.
- `simulation/`: adaptive-learning simulation and analysis.
- `debug/`: quick local diagnostics.
- `prototypes/`: experimental assets.

Examples:

- `python scripts/db/create_tables.py`
- `python scripts/seed/seed_data.py`
- `python scripts/seed/seed_exercises.py`
- `python scripts/simulation/simulate_learning.py`
- `python scripts/simulation/analyze_simulation.py --input simulation_results.csv`
